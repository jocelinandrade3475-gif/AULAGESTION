# AULAGESTION# 🎓 AulaGestion — Sistema de Gestión de Alumnos (Metodología SCRUM)

Proyecto final desarrollado bajo el marco de trabajo ágil **SCRUM** para el control escolar, registro de estudiantes y seguimiento académico.

## 📋 Archivos del Repositorio
* `index.html` — Interfaz principal de AulaGestion y menú integrado de entregables del curso.
* `styles.css` — Hoja de estilos responsiva, diseño institucional y etiquetas de estatus académico.
* `app.js` — Lógica CRUD de alumnos, validación de matrícula única, búsqueda en tiempo real y persistencia en `localStorage`.

## 🚀 Funcionalidades Principales
1. **Registro y Validación de Alumnos:** Alta de estudiantes con matrícula única, grupo, promedio (0.0 a 10.0) y estatus académico (*Activo*, *En Riesgo*, *Baja Temporal*).
2. **Búsqueda y Filtrado Instantáneo:** Localización rápida por matrícula, nombre o grupo, además de filtrado por estatus.
3. **Menú Integrado del Curso:** Acceso directo desde la barra superior al sistema implementado, actividades realizadas en los Sprints, reporte de modificaciones y estructura del código comprimido.

## 💻 Ejecución Local
1. Descarga el proyecto (`Code > Download ZIP`) y descomprímelo.
2. Haz doble clic en `index.html` para abrirlo en cualquier navegador web.
