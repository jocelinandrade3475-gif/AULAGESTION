📦 Estructura del Proyecto AulaGestion

El sistema está construido con tecnologías web estándar sin dependencias externas pesadas:

aulagestion-scrum.zip
├── index.html      # Interfaz principal de AulaGestion y menú de entregables
├── styles.css      # Estilos responsivos, tabla de alumnos y estados visuales
├── app.js          # Lógica CRUD, validación de matrículas, filtros y localStorage
└── README.md       # Documentación técnica del repositorio en GitHub

Repositorio GitHub: Disponible para descarga directa desde Code > Download ZIP o clonación vía Git.
